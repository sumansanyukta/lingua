# Lingua Account Creation Screen — Detailed UI/UX Layout Specification

This document provides a complete layout and visual specification for the **Create Your Account** UI screen based on the Lingua Design System.

---

## 1. Viewport & Navigation Bar

* **Canvas:** Mobile Viewport (`#FFFFFF` background)
* **Status Bar:** Top-aligned; time (`9:41`) on left, signal/Wi-Fi/battery icons on right.
* **Top Navigation:** Left-aligned back chevron arrow (`<`) in dark primary text color (`#0D132B`).

---

## 2. Header & Mascot Hero

* **Title (H1):** `"Create your account"` — `32px`, Bold (`700`), `#0D132B`, left-aligned.
* **Subtitle:** `"Start your language journey today ✨"` — `16px`, Regular (`400`), `#6B7280`, left-aligned.
* **Mascot Illustration:** Centered half-body visual of the Lingua Fox waving, surrounded by small yellow and blue sparkle vectors.

---

## 3. Form Input Fields

Both input containers feature a white surface (`#FFFFFF`), light gray border (`#E5E7EB`), and rounded corners (`16px`).

* **Email Field:**
  * **Floating Label:** `"Email"` (`11px`/`13px`, `#6B7280`)
  * **Input Value:** `"alex@gmail.com"` (`16px`, Medium, `#0D132B`)
* **Password Field:**
  * **Floating Label:** `"Password"` (`11px`/`13px`, `#6B7280`)
  * **Input Value:** Obscured password bullets (`••••••••`)
  * **Action Icon:** Eye toggle icon on the far right (`#6B7280`)

---

## 4. Primary CTA Button

* **Label:** `"Sign Up"` (`18px`, SemiBold `600`, `#FFFFFF`, centered)
* **Background:** Lingua Purple gradient (`#6C4EF5` / `#5B3BF6`)
* **Dimensions:** Full width with `24px` horizontal padding, height `56px`, `20px` border radius.

---

## 5. Divider & Social Auth Options

* **Divider:** Horizontal line (`#E5E7EB`) centered with text `"or continue with"` (`13px`, `#6B7280`).
* **Social Buttons:** White cards with `#E5E7EB` border, `16px` border radius, centered flex layout.
  1. **Google:** Colored Google "G" logo + `"Continue with Google"` (`#0D132B`, SemiBold `600`)
  2. **Facebook:** Blue Facebook circle logo + `"Continue with Facebook"` (`#0D132B`, SemiBold `600`)
  3. **Apple:** Black Apple logo + `"Continue with Apple"` (`#0D132B`, SemiBold `600`)

---

## 6. Footer Navigation Link

* **Position:** Centered at bottom.
* **Text:** `"Already have an account? "` in secondary text (`#6B7280`).
* **Interactive Link:** `"Log in"` in Lingua Purple (`#6C4EF5`, SemiBold `600`).
